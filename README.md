# Student Grade Calculator - Java

A simple console-based Java application that calculates student grades based on marks.

## Features
- Takes marks as input
- Calculates Total, Average & Percentage
- Assigns Grade (A, B, C, Fail)
- Input validation

## Tech Stack
Java, OOPs Concepts, Scanner Class

## How to Run
javac StudentGradeCalculator.java
java StudentGradeCalculator
